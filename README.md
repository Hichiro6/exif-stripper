# EXIF Stripper

> Remove EXIF metadata from photos in your browser. Protect your privacy — strip GPS, camera info, and more. 100% local.

## Features

- **Privacy-first** — No backend, no uploads, no tracking. Everything happens in your browser.
- **No installation** — Works directly in the browser.
- **Accessible** — ARIA-compliant, keyboard navigation, screen reader support.

## Tech Stack

- [Vite](https://vitejs.dev/)

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Testing

```bash
npm run test:run
```
